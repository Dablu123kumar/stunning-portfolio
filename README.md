## 🚀 Features

- ✨ **Stunning Dark Theme** with glassmorphism UI
- 🎆 **Particle Canvas** with interactive mouse effects
- ⌨️ **Typewriter effect** for roles & name
- 📊 **Animated skill bars** with tab-based filtering
- 🖱️ **Custom cursor** with hover effects
- 🃏 **3D card tilt** on hover
- 📱 **Fully Responsive** across all devices
- ♿ **Accessible** with ARIA labels and semantic HTML
- 🔍 **SEO Optimized** with meta tags
- ⚡ **Zero dependencies** — pure HTML, CSS, JavaScript

## 🚀 Deployment

### GitHub Pages
1. Push to GitHub: `git push origin main`
2. Go to **Settings → Pages**
3. Set source to `main` branch → `/` (root)
4. Your site is live at `https://<username>.github.io/<repo>`

### Vercel (Recommended)
```bash
npx vercel --prod
```

### Netlify
Drag & drop the `portfolio/` folder at [netlify.com/drop](https://app.netlify.com/drop)
